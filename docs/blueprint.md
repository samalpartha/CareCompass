# **App Name**: CareCompass

## Core Features:

- Simple Onboarding: Gathers basic info: care recipient's name and stage of condition.
- Daily Care Log: Enables caregivers to log daily observations with text and quick-select tags.
- AI Visit Summary Generator: Generates a structured summary for doctor visits from the recent care logs, acting as a tool.
- Data Visualization: Presents simple charts for key metrics like confusion occurrences and caregiver mood trends.

## Style Guidelines:

- Primary color: Soft blue (#79BAEC), evoking calmness and trust.
- Background color: Very light blue (#F0F8FF), providing a gentle and unobtrusive backdrop.
- Accent color: Soft green (#8FBC8F), for a touch of reassurance and growth.
- Body and headline font: 'PT Sans' for readability and a modern, approachable feel.
- Use heart and home icons for key elements.
- Gentle transitions and micro-interactions to provide feedback without overwhelming the user.
- Clear, spacious layouts with large, accessible buttons for easy navigation.
